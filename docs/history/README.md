# Documentation history archive

**Historical status:** everything below this directory is non-normative. Start
with the [current documentation index](../README.md). Use these records only for
chronology, rationale, provenance, or forensics.

## Archive map

- [`runtime/`](runtime/README.md): superseded runtime generations, grouped as
  DS7, DS8 (including captured vendor reference notes), and container-era
  DS9.1/DS9.0 material.
- [`audits/`](audits/README.md): completed transition and implementation audits,
  including the DS9 native-port bridge reports.
- [`experiments/`](experiments/README.md): completed or rejected model,
  pipeline, and feature investigations that are not the current baseline.
- `upgrade_projects/`: completed implementation records retained for provenance,
  including the initial MapAnything integration.
- `debug/`: dated troubleshooting diaries retained for forensics, not current
  diagnosis.
- `documentation_index_pre_native_20260815.md`: snapshot of the active index
  immediately before the native DS9.1 documentation superseded it.

Completed and superseded work orders live in the
[plans archive](../../plans/archive/README.md), including the DS9 native-host
migration records. Historical agent policies have been renamed to
`agent_policy_snapshot.md`; they do not override repository guidance.

Archived commands, version pins, paths, diagrams, and acceptance states may be
wrong for the current host. Do not execute them without re-deriving the action
from current source, configuration, and [repository policy](../../AGENTS.md).
