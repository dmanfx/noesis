# Documentation history archive

Everything below this directory is non-normative. Start with
`../README.md` and use archived material only for chronology, rationale, or
forensics.

## Contents

- `ds7/`: pre-Service-Maker runtime and pipeline documentation.
- `ds8/`: DS8 architecture, contracts, baselines, migration work, model notes,
  and the last pre-native documentation snapshots.
- `deepstream8_reference/`: captured DeepStream 8 reference notes used during
  the earlier migration.
- `experiments/`: completed model/promotion plans that never became the current
  baseline, including the original DS8 test-pipeline operating notes.
- `upgrade_projects/`: completed integration work orders, including the initial
  MapAnything service/UI implementation that was later absorbed into DS9.1.
- `ds9_container/`: checkout-identity and LAN/container instructions superseded
  by native execution and Menon's browser boundary.
- `debug/`: dated troubleshooting diaries retained for forensics, not current
  diagnosis.
- `documentation_index_pre_native_20260815.md`: the previous active index at
  the point the native DS9.1 documentation superseded it.

DS9.0/container-era DS9.1 records live separately in
`../../DS9/docs/history/`. Completed work orders live in
`../../plans/archive/`.

Archived commands, version pins, paths, diagrams, and acceptance states may be
wrong for the current host and must not be executed without re-deriving them
from current source and configuration.
