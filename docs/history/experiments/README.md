# Completed experiment archive

**Historical status:** this directory contains completed, rejected, or
superseded model, pipeline, UI, and feature investigations. Presence here does
not make a capability supported or enabled.

- `model_generation/` and `onnx2trt/`: model-export and conversion records.
- `testpipelines/`: retired DS8 test-pipeline notes.
- Remaining files: bounded investigations and proposals retained for their
  evidence or rationale.

Use [runtime_baseline.md](../../runtime_baseline.md) and current DS9
configuration to determine supported models and capabilities.
