# DeepStream 8 documentation archive

**Historical status:** DeepStream 8 is retired. These files preserve its last
architecture, contracts, baselines, migration notes, implementation work
records, and pre-native snapshots. They are not instructions for the native
DeepStream 9.1 application.

The archive includes:

- DS8 architecture and operating snapshots (`DS8_*`, `CODEBASE_DESCRIPTION.md`,
  and `README_pre_ds91_native_20260815.md`);
- migration and feature work records (`ds8_*`);
- [`vendor_reference/`](vendor_reference/README.md), a captured DS8 reference
  set used during migration; and
- `visuals/`, containing the retired DS8 V3DT and GPU/CPU diagrams formerly in
  the active documentation directory.

Additional completed DS8 work orders live in the
[plans archive](../../../../plans/archive/ds8/). For current runtime authority,
return to the [documentation index](../../../README.md).
