# Container-era DS9 documentation archive

**Historical status:** these records describe DS9.0 and container-era DS9.1
deployment, ownership, driver migration, staging, and LAN behavior. The
canonical Noesis application now runs DeepStream 9.1 directly on the host.

The two `*_pre_native_20260815.md` files are documentation snapshots. The
remaining files preserve container boundary, ownership-evidence, driver, and
gateway chronology. None defines a supported container fallback.

For current operation use the [DS9 documentation index](../../../../DS9/docs/README.md)
and [native runtime boundary](../../../../DS9/docs/runtime_host_boundary.md).
