Install RoomWalk for Android

Two capture modes: room reconstruction with additional views, and a body-held path walk paired with Noesis. Both retain native video and IMU data.

Version 0.4.2 · 894.9 kB · Android 13 or newer for recording

Tap Prepare APK in browser, then Save APK to phone. Keep this page open until Chrome finishes saving the file.

  1. Open this page in your phone’s regular browser. Tap Prepare APK in browser, wait for the file check, then tap Save APK to phone.
  2. After the browser finishes saving the APK, open it from Downloads. Android may ask to allow installation from that browser or file manager.
  3. Open RoomWalk, allow camera access, and tap Check phone. Choose Reconstruction or Path refinement. Open the camera and complete its 10-second recording check if requested.

Reconstruction: capture many sharp, overlapping views. Optionally select an existing reconstruction, then explicitly add the new capture’s views from Library. A paired room camera is optional.

Path refinement: choose the reconstruction marked Noesis PCF to use its exact retained fused version. For the Living Room, choose living room walk · Noesis PCF and the Living Room camera. The selected revision stays with the recording; it cannot silently fall back to the original raw reconstruction.

Hold the phone against your own torso with elbows tucked; turn and move your whole body with the phone. Stop, save and upload from Library. Process the path with DA3, align the new walk to its paired static camera, then run path review. The selected PCF room already has its verified registration. An ordinary raw reference still needs its own matching alignment. Review shows the phone path beside the paired Noesis track, with a time slider and downloads. Rejected corrections leave the original path intact; the desired 10 cm accuracy is not yet validated.

Install over the existing app. Do not uninstall or clear its data. The same signing key preserves saved captures and settings. Original video, IMU streams, calibration evidence and older recordings remain available.

Full calibration is optional under Setup. Ordinary capture uses automatic focus without requiring a board calibration. Recording-mode/timestamp checks still apply; a locked-focus calibration test does not qualify a different automatic recording mode.

Native recording opens in landscape; uploads continue with the screen off. Use RoomWalk server 1.13.0 or newer. Native 8K support must still be checked on the physical phone; emulator validation is not an 8K recording test.
